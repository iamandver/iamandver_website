Braille Converter

This is a little experiment I have been working on recently. I really love ASCII art and was wondering if I could push it far enough to be used as game graphics. Then I discovered Braille characters, which is a great way to represent a 2 by 4 pixel cluster. So I wrote a little image converter that takes any image and uses Braille characters to represent it as best as possible. What's really cool is that each character gets only one color, so the resulting image has a lower color resolution so to speak, which makes for very interesting patterns. I have not started working on a game yet that might use this as graphics, but the image generation itself is pretty cool. There are a few parameters for you to play around with too. Have fun!
